# pokeapi-java-cli

名前の文字数からポケモンを1匹引っ張ってくる、Java製の簡単なコンソールツールである。
PokeAPIをJavaから叩いてみる練習として作成。

## 作成経緯

以前、React + PHP でポケモン図鑑を作成。<https://github.com/wataru-creato/PokemoAPI-React-App>
今見直すと、フロントエンドから直接APIと通信しているなど、責務の分け方に改善の余地があると実感した。

今後このアプリを **Javaのバックエンド** として再作成を検討する。
その第一歩として、まずは「JavaでAPIを叩けるか」を試すために、このコンソールツールを作成した。

## 何ができるか

1. 名前を入力する
2. 名前の文字数をもとに、ポケモンを1匹取得する
3. 取得したポケモンの情報を表示する

文字数をきっかけに、全1025匹の中からランダム感覚でポケモンが出てくる。
凝った機能はなく、あくまで「JavaからAPIを叩く」ことの確認が目的である。

## 使用技術

- Java
- Gradle
- [PokeAPI](https://pokeapi.co/)

## 使い方

### 必要なもの

- JDK（インストール済みであること）
- インターネット接続（PokeAPIにアクセスするため）

### 実行方法（Windows）

リポジトリのルートで `run.bat` を実行します。

```bat
run.bat
```
※bat内のディレクトリを書き換えてから使用してください。
  
画面の案内に従って名前を入力してください。

## ディレクトリ構成

```
pokeapi-java-cli
├── src/main        # ソースコード
├── gradle/wrapper  # Gradle Wrapper
├── build.gradle
├── settings.gradle
└── run.bat         # 起動用バッチ
```
